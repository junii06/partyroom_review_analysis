# partyroom_review_analysis

## 🏠프로젝트 제목
경기도 성남시 모란역 인근 파티룸 A,B,C 리뷰 분석

---

## 📌프로젝트 개요
네이버 지도 리뷰 데이터(2025년 10월 기준)를 수집하여</br>
모란역 인근 파티룸 3곳의 고객 이용 패턴, 방문 목적, 만족 요소를 분석한 프로젝트입니다.</br>

리뷰 텍스트와 방문 정보를 기반으로 고객 반응을 파악하고,</br>
공간 운영 및 고객 경험 개선에 활용할 수 있는 인사이트 도출을 목표로 진행되었습니다.

---

## 🔍데이터 개요
- 데이터 출처: 네이버 지도 리뷰
- 분석 대상: 모란역 인근 파티룸 A, B, C
- 데이터 규모: 총 283건
  - A 파티룸: 230건
  - B 파티룸: 47건
  - C 파티룸: 6건
- 수집 항목: 리뷰 ID, 리뷰 내용, 방문 일자, 방문 시간대, 방문 횟수, 키워드

---

## 📊분석 내용
1. 수요 패턴 분석</br>
   : 방문 월, 요일, 시간대별 이용 패턴 도출
2. 충성도 분석</br>
   : 리뷰 작성자 기준 재방문 의사 표현과 실제 재방문 기록 비교
3. 키워드 분석</br>
   : 리뷰 내 주요 키워드 기반 만족 요인 도출
4. 이벤트 유형 분석</br>
   : 방문 목적 분류 및 이벤트성 방문 비율 확인
5. 긍·부정 요인 분석</br>
   : 공간·서비스 요소별 고객 반응 분석

---

## 💡주요 인사이트
- **12월, 주말, 올나잇 시간대**에 수요 집중
- **이벤트성 모임**이 파티룸 방문의 주요 동기로 작용
- 인테리어, 공간 크기, 청결 등 **공간·시설** 관련 만족 요소가 주요 강점으로 나타남 
- 재방문 의사 표현은 높았지만 실제 재방문 기록은 상대적으로 낮게 나타남 → **고객 유지 전략** 필요
- **B,C파티룸**은 리뷰 수 부족으로 고객 인식 파악 한계 →  **리뷰 작성 유도 방안** 필요
- **화장실/주차 불만**등 접근성과 편의성 관련 불편 요소는 향후 공간 운영 및 신규 공간 기획 시 **개선 포인트**로 확인

---

## 🧰사용 기술 및 라이브러리<br>
**언어**
- Python
- Word: 기획안 리포트, 시각 자료 정리

**라이브러리**
- pandas: 데이터 불러오기, 데이터프레임 형태로 저장
- Selenium: 네이버 지도 리뷰 데이터 수집
- BeautifulSoup: HTML 파싱 및 리뷰 데이터 추출
- hashlib: id 비식별화(sha256 활용)
- ast: 문자열 형태의 리스트를 실제 python 객체로 변환
- konlpy: 한국어 형태소 분석(Okt 분석기 활용)
- collections: 단어 출현 빈도 계산 및 키워드 집계에 활용(Counter)
- re: 리뷰 텍스트 분리, 불필요한 공백 제거

## ⚠한계점
- 파티룸별 리뷰 수 편차가 커 A 파티룸을 중심으로 분석하고, B·C파티룸은 보조 자료로 활용했습니다.
- 네이버 지도 리뷰 특성상 긍정 리뷰 편향이 존재할 수 있습니다.
- 재방문율은 리뷰 작성자 ID 기준으로 제한적으로 추정했기 때문에 실제 고객 충성도와 차이가 있을 수 있습니다.
- 긍·부정 분류는 사전 기반으로 진행되어 리뷰 맥락을 함께 고려하여 해석했습니다.
